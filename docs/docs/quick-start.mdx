# Quick Start

Install the plugin, point a collection at Bunny Storage, and optionally route video to Bunny Stream.

<Steps>

### Install

<PackageManagerTabs
  command={{
    npm: 'npm install @seshuk/payload-storage-bunny',
    yarn: 'yarn add @seshuk/payload-storage-bunny',
    pnpm: 'pnpm add @seshuk/payload-storage-bunny',
  }}
/>

<Callout type="info">

Requires Payload CMS 3.83.0 or later and Node.js 22 or later.

</Callout>

### Configure storage

Add the plugin to your Payload config and map an upload collection to Bunny Storage:

```ts title="payload.config.ts"
import { bunnyStorage } from '@seshuk/payload-storage-bunny'

export default buildConfig({
  collections: [
    // your upload collections, e.g. Media
  ],
  plugins: [
    bunnyStorage({
      collections: {
        media: true,
      },
      storage: {
        apiKey: process.env.BUNNY_STORAGE_API_KEY,
        hostname: process.env.BUNNY_STORAGE_HOSTNAME, // e.g. my-zone.b-cdn.net
        zoneName: process.env.BUNNY_STORAGE_ZONE_NAME,
      },
    }),
  ],
})
```

Files uploaded to the `media` collection are now stored in Bunny Storage and served from the CDN.

### Add video streaming (optional)

To route video uploads to Bunny Stream, add a `stream` block. Non-video files continue to use Bunny Storage.

```ts title="payload.config.ts"
bunnyStorage({
  collections: { media: true },
  storage: {/* ... */},
  stream: {
    apiKey: process.env.BUNNY_STREAM_API_KEY,
    hostname: process.env.BUNNY_STREAM_HOSTNAME, // e.g. vz-xxxx.b-cdn.net
    libraryId: Number(process.env.BUNNY_STREAM_LIBRARY_ID),
    mp4Fallback: true,
  },
})
```

With Payload access control on (the default), Stream needs `mp4Fallback: true` or signed URLs with redirect — otherwise the plugin throws at startup. See [Access control and mp4Fallback](/configuration/stream#access-control-and-mp4-fallback).

Videos now upload to Bunny Stream and expose an HLS playlist through the [`bunnyData`](/stored-data) field.
